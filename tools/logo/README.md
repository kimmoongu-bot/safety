# 로고 글자 — '잠김' 을 도형으로 그린 것

아직 아이콘을 정하지 않았다. 여기 있는 것은 글자 모양뿐이다.

## 왜 글꼴을 안 쓰나

이 저장소에서 쓸 수 있는 한글 글꼴은 GPL 중국어 글꼴 하나뿐이라, 스토어에 파는 앱
로고에 넣기 곤란하다. 로고는 원래 글꼴로 찍는 것이 아니라 그리는 것이기도 하다.
직접 그리면 획 두께·자간·라이선스를 우리가 정한다.

`hangul.py` 의 도형이 최종 그림이다. 글꼴은 `overlay.py` 에서 **자로 재는 용도로만**
쓴다 — 내가 그린 글자를 진짜 글자 위에 겹쳐 어긋난 곳을 보는 것이다. 그 결과물은
확인용이고 앱에 들어가지 않는다.

## 겹쳐 보고 고친 것

눈대중으로 좌표를 찍었더니 글자가 제대로 안 읽혔다. 겹쳐 보고 셋을 고쳤다.

- **받침 ㅁ 이 너무 크고 넓었다.** 칸을 꽉 채우니 글자를 짓눌러 다른 글자처럼 보였다.
  ㅁ 은 위 자모보다 좁고 낮다.
- **ㅈ 의 삐침이 짧았다.** 짧으면 ㅅ 처럼 보인다.
- **ㄱ 의 다리가 곧게 내려왔다.** 그러면 옆의 ㅣ 와 나란해져 다른 글자로 읽힌다.
  안쪽으로 기울여야 한다.

## 쓰는 법

```
pip install Pillow
python3 overlay.py      # 진짜 글자 위에 겹쳐 확인 → overlay.png
```

## 남은 결정

- 색: **파란색은 쓰지 않기로 했다.** 나머지는 미정.
- 자물쇠 형태를 같이 넣을지, 글자만 갈지
