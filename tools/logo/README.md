# 로고 · 아이콘

## 정해진 것

| | |
|---|---|
| 바탕 | 먹색 `#1E232B` |
| 그림·글자 | 흰색 |
| 배치 | 자물쇠 위, `잠김` 아래 |

파란색은 쓰지 않는다.

## 왜 글꼴을 안 쓰나

이 저장소에서 쓸 수 있는 한글 글꼴은 GPL 중국어 글꼴 하나뿐이라, 스토어에 파는 앱
로고에 넣기 곤란하다. 로고는 원래 글꼴로 찍는 것이 아니라 그리는 것이기도 하다.
직접 그리면 획 두께·자간·라이선스를 우리가 정한다.

`hangul.py` 의 도형이 최종 그림이다. 글꼴은 `overlay.py` 에서 **자로 재는 용도로만**
쓴다 — 내가 그린 글자를 진짜 글자 위에 겹쳐 어긋난 곳을 보는 것이고, 그 결과물은
앱에 들어가지 않는다.

## 만드는 법

```
pip install Pillow
python3 tools/logo/make_assets.py
```

나오는 것:

| 파일 | 쓰임 |
|---|---|
| `assets/icon.png` (1024²) | 앱 아이콘 |
| `assets/adaptive-icon.png` (1024², 투명) | 안드로이드 적응형 아이콘의 앞면 |
| `assets/notification-icon.png` (192², 투명) | 알림줄 아이콘 |
| `docs/store/feature-graphic.png` (1024×500) | 구글 플레이 대표 그래픽 |

확인용:

```
python3 tools/logo/overlay.py    # 진짜 글자 위에 겹쳐 보기 → overlay.png
```

## 실수해서 배운 것

**글자를 그릴 때는 반드시 진짜 글자와 겹쳐 확인한다.** 눈대중으로 좌표를 찍었다가
아래 넷을 냈다.

- **`ㅏ` 의 곁줄기를 세로획 왼쪽에 그렸다.** 그러면 `ㅓ` 다. `잠김` 이 `점검` 으로
  읽혔고, 그 상태로 색 후보까지 다 만들어 보여 줬다. 곁줄기는 **오른쪽**이다.
- **받침 `ㅁ` 이 칸을 꽉 채웠다.** 글자를 짓눌러 다른 글자처럼 보였다. `ㅁ` 은 위
  자모보다 좁고 낮다.
- **`ㅈ` 의 삐침이 짧았다.** 짧으면 `ㅅ` 처럼 보인다.
- **`ㄱ` 의 다리가 곧게 내려왔다.** 옆의 `ㅣ` 와 나란해져 다른 글자로 읽힌다.
  안쪽으로 기울여야 한다.

**아이콘 크기도 눈대중으로 잡지 않는다.** `make_assets.py` 의 `fit()` 은 그림을 투명
바탕에 한 번 그린 뒤 **실제로 잉크가 닿은 사각형을 재서** 원하는 자리에 맞춘다.
눈대중으로 했을 때 적응형 아이콘이 콩알만 해지고 알림 아이콘은 잘렸다.

## 크기 규칙

- **적응형 아이콘**: 폰마다 아이콘을 동그라미·둥근 네모·네모·물방울로 깎는다.
  바깥쪽은 잘려 나가므로 그림은 가운데 62% 안에만 둔다 (안드로이드 보장선은 66%).
  바탕은 그림에 넣지 않고 `app.json` 의 `backgroundColor` 가 깐다.
- **알림줄 아이콘**: 흰 실루엣 + 투명 배경만 쓸 수 있다. 색은 OS 가 입힌다.
  이 크기에서 글자와 열쇠구멍은 뭉개지므로 자물쇠 모양만 남긴다.

## 국제화

아이콘은 나라별로 다르게 넣기 어렵다. 하나가 전 세계에 똑같이 나간다.
그래서 **자물쇠(어디서나 통함) + 잠김(한국 사용자에게는 이름, 다른 곳에서는 무늬)**
구조로 갔다. 자세한 것은 `docs/국제화.md`.
