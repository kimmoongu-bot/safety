# 스토어 소개 문구 (초안)

`docs/스토어-데이터-안전.md` 의 문구 규칙을 지킨다. **"절대 안전", "해킹 불가",
"군용 등급", "100% 보안", "완벽한 보호" 는 쓰지 않는다.** 지킬 수 없는 약속이고
심사에서도 걸린다.

읽는 분이 중장년층이다. 전문 용어를 쓰지 않고, 한 문장을 짧게 끊는다.

---

## 앱 이름 (30자 이내)

```
잠김 — 비밀번호 보관함
```

`잠김` 만으로는 무슨 앱인지 검색에서 알 수 없다. 뒤를 붙이되 "관리자" 대신
**"보관함"** 을 쓴다 — 관리는 앱이 하는 일이 아니라 사람이 하는 일처럼 들리고,
보관함은 무엇을 하는 물건인지 바로 보인다.

## 간단한 설명 (80자 이내)

```
아이디와 비밀번호를 폰 안에만 적어 둡니다. 서버도 계정도 없습니다.
```

35자. **"서버도 계정도 없습니다"** 가 이 앱의 유일한 진짜 차별점이라 짧은 줄에
넣는다. 목록에서 이 한 줄만 보고 지나가는 사람이 많다.

## 자세한 설명

```
종이에 적어 둔 비밀번호를 옮겨 담는 곳입니다.

가입도, 로그인도, 서버도 없습니다. 적은 내용은 이 폰 안에만 있습니다.


■ 무엇을 할 수 있나요

· 어디에서 쓰는 것인지, 아이디, 비밀번호를 적어 둡니다
· 다른 앱 로그인 칸에서 잠김을 눌러 바로 넣을 수 있습니다
· 큰 글씨, 큰 단추. 폰의 글꼴 크기 설정을 그대로 따릅니다
· 백업 파일을 만들어 두면 폰을 바꿔도 옮길 수 있습니다


■ 어떻게 지키나요

· 저장할 때 내용을 암호로 잠급니다 (AES-256-GCM)
· 서버가 없습니다. 내용이 기기 밖으로 나가지 않습니다
· 인터넷 권한을 요청하지 않습니다. 권한 목록에서 확인해 보세요
· 폰을 잃어버려도 저장된 내용은 암호문으로 남습니다
· 화면 잠금(숫자) 또는 지문으로 엽니다


■ 꼭 알아 두실 것

숫자(PIN)와 복구 코드와 백업 파일이 모두 없으면 되살릴 수 없습니다.
저희에게도 사본이 없기 때문입니다.

복구 코드는 금고를 만들 때 한 번 보여 드립니다. 종이에 적어 서랍에 두세요.


■ 이런 분께

· 비밀번호를 수첩이나 쪽지에 적어 두시는 분
· 클라우드에 올리는 것이 께름칙하신 분
· 글씨가 작아 잘 안 보이시는 분


한국어 · English · 日本語 · Русский
```

## 왜 이렇게 썼나

**"종이에 적어 둔 비밀번호를 옮겨 담는 곳"** 으로 시작한다. "비밀번호 관리
솔루션" 이라고 쓰면 그게 무엇인지 아는 사람만 읽는다. 우리 손님은 수첩에 적어
두시는 분이고, 그 수첩을 첫 줄에 놓아야 자기 이야기로 읽힌다.

**"인터넷 권한을 요청하지 않습니다. 권한 목록에서 확인해 보세요"** — 확인해 보라고
적는다. 말로만 하는 약속과 달리 이건 스토어 화면에서 누구나 그 자리에서 확인할
수 있다. 확인할 수 있는 약속만 값이 있다.

**"꼭 알아 두실 것" 을 숨기지 않는다.** 되살릴 수 없다는 말은 파는 데 도움이 안
된다. 그래도 앞쪽에 크게 적는다 — 모르고 잃는 것보다 알고 안 쓰는 편이 낫다.
문구 규칙에도 이 문장은 반드시 넣게 되어 있다.

**"AES-256-GCM" 을 굳이 적는 이유.** 중장년층은 이게 뭔지 모르신다. 대신 자녀분이
읽는다. "안전합니다" 열 줄보다 이 한 줄이 확인 가능한 말이다.

## 아직 안 정한 것

- **다른 언어 문구.** 앱은 네 말을 하는데 스토어 문구는 한국어만 있다. 처음에는
  한국 시장만 열고, 뒤에 옮긴다. 옮길 때 원어민 검토와 함께 한다
- **스크린샷 8장** — 폰에서 찍어야 한다. 글꼴 200% 확대 상태 1장을 반드시 넣는다
  (`docs/스토어-데이터-안전.md`)
- **개인정보 처리방침 웹 주소** — 문서는 있는데 올릴 곳이 없다
