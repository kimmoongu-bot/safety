# 안드로이드 설치 파일 만들기

폰에 깔아서 직접 눌러 볼 수 있는 파일(`.apk`)을 만드는 방법이다.
컴퓨터에 개발 도구를 깔지 않아도 되는 방법을 먼저 적는다.

---

## 방법 1 — 클라우드에서 만들기 (권장)

Expo 서버가 대신 빌드해 주고, 다 되면 내려받을 주소와 QR 코드를 준다.
컴퓨터에는 Node 만 있으면 된다. 안드로이드 스튜디오는 필요 없다.

### 준비

1. Expo 계정을 하나 만든다 (무료): https://expo.dev/signup
2. 이 저장소를 컴퓨터에 받아 둔다.

```bash
git clone https://github.com/kimmoongu-bot/safety
cd safety
npm install
```

### 만들기

```bash
npx eas-cli login          # 방금 만든 계정으로 로그인
npx eas-cli build --platform android --profile preview
```

처음 한 번은 "앱 서명 열쇠를 만들까요?" 하고 묻는다. **예**를 고르면 Expo 가
알아서 만들어 보관한다. 직접 관리하고 싶으면 그때 골라도 된다.

10~20분쯤 지나면 내려받을 주소가 나온다. 그 주소를 폰으로 열면 `.apk` 파일을
받을 수 있다.

### 폰에 깔기

1. 받은 파일을 누른다.
2. "출처를 알 수 없는 앱"을 허용하겠냐고 물으면 허용한다.
   (스토어를 거치지 않은 파일이라 그렇다. 설치가 끝나면 다시 꺼도 된다.)
3. 홈 화면에 **잠김** 이 생긴다.

---

## 방법 2 — 컴퓨터에서 직접 만들기

안드로이드 스튜디오가 이미 깔려 있다면 이쪽이 더 빠르다.

```bash
npm install
npx expo prebuild --platform android
cd android && ./gradlew assembleRelease
```

만들어진 파일: `android/app/build/outputs/apk/release/app-release.apk`

USB 로 폰을 연결한 상태라면 아래 한 줄로 바로 깔린다.

```bash
npx expo run:android --variant release
```

---

## 빌드 종류

`eas.json` 에 세 가지를 적어 두었다.

| 이름 | 무엇 | 언제 |
|---|---|---|
| `preview` | 혼자 도는 `.apk` | **폰에 깔아서 눌러 볼 때. 지금 필요한 것.** |
| `development` | 개발용 `.apk` | 고치면서 볼 때. 컴퓨터에서 `npm start` 를 띄워 둬야 한다 |
| `production` | `.aab` | 구글 플레이에 올릴 때 |

## 깔고 나서 확인할 것

명세 8장이 요구하는 항목이다. 순서대로 눌러 보고 안 되는 것을 알려 주면 고친다.

- [ ] 최초 설정 — PIN(핀) 만들기 → 지문 쓸지 고르기 → 복구 코드 적고 다시 입력
- [ ] 잠갔다가 PIN(핀)으로 열기 / 지문으로 열기
- [ ] 항목 넣기 → 찾기 → 보기 → 복사 → 고치기
- [ ] 복사한 비밀번호가 60초 뒤에 실제로 지워지는지
- [ ] 앱을 잠깐 나갔다 오면 잠기는지, 최근 앱 목록에 내용이 안 보이는지
- [ ] PIN(핀)을 5번 틀리면 30초 기다리라고 하는지, 앱을 껐다 켜도 그 대기가 남는지
- [ ] 백업 파일 만들어 카카오톡으로 보내 보기 → 지운 뒤 그 파일로 되살리기
- [ ] 설정 → 글씨 크기를 가장 크게 (200%) 해 놓고 여덟 화면 모두 써 보기

### 특히 눈여겨볼 것

**첫 화면에서 PIN(핀)을 만들 때 몇 초 걸리는지** 봐 주면 좋겠다.
기기 성능에 맞춰 열쇠 만드는 세기를 정하는 과정인데, 0.5~1초가 목표다.
너무 오래 걸리거나(3초 이상) 너무 빠르면(0.1초 이하) 알려 달라. 값을 조정해야 한다.

만약 **PIN(핀)을 만드는 중에 앱이 죽으면** 암호 라이브러리 문제다.
`docs/완료기준.md` 의 "착수 전 확인 사항"에 적어 둔 세 가지 중 하나이며,
그때는 다음 후보(scrypt → PBKDF2)로 내려가도록 손보면 된다.
