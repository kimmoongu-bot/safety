# 잠김 — 제품 소개와 홍보 방향

이 문서는 **팔기 위한 문서**다. 다만 명세 8장이 정한 선을 넘지 않는다.

> `docs/위협모델.md` 의 표가 모든 문구의 기준이다.
> **그 표보다 강한 말은 어떤 매체에서도 쓰지 않는다.**
> "절대 안전", "해킹 불가", "군사급" 같은 표현은 쓰지 않는다.

---

## 1. 한 줄로

**아이디와 비밀번호를 내 폰 안에만 넣어 두는 금고.**
서버가 없고, 계정을 만들지 않고, 인터넷 권한조차 요구하지 않는다.

## 3. 기능

**금고**
- 아이디·비밀번호·메모를 넣고, 찾고, 고치고, 지운다
- 자주 쓰는 것 즐겨찾기
- 비밀번호를 바꾸기 전 것 하나를 남겨 둔다 (새 비밀번호가 안 될 때 되돌리려고)

**여는 방법 세 가지**
- PIN(핀)
- 지문·얼굴
- 복구 코드 16자 (PIN 을 잊었을 때)

**백업**
- `.jamgim` 파일 하나로 통째 내보내기
- 앱 PIN 과 **다른** 백업 비밀번호로 잠근다
- 마지막 백업 후 90일이 지나면 알림

**지키는 장치**
- 자동 잠금 (기본 1분)
- 다른 앱으로 넘어가는 즉시 잠금
- 복사한 비밀번호를 60초 뒤 지움
- 비밀번호를 보여 준 뒤 15초 뒤 다시 가림
- 최근 앱 목록·화면 캡처 차단
- OS 자동 백업 대상에서 금고 파일 제외

## 4. 보안 능력

### 4.1 지키는 것

`docs/위협모델.md` 의 표를 그대로 옮긴다. **이 표가 홍보 문구의 상한선이다.**

| 상황 | 결과 |
|---|---|
| 잠긴 폰을 잃어버리거나 도둑맞음 | 방어 |
| 백업 파일만 유출됨 | 방어 |
| 루팅 안 한 기기에서 앱 데이터를 통째로 빼감 | 방어 |
| 어깨너머로 훔쳐보기 | 부분 방어 |
| 루팅·탈옥된 기기 | **완전 방어 불가** |
| 키로거·악성앱에 감염된 기기 | **방어 불가** |
| 잠금 푼 상태로 남에게 폰을 넘김 | 부분 방어 |

**마지막 두 줄을 숨기지 않는다.** 입력 자체를 가로채는 악성앱 앞에서는 어떤 비밀번호
관리자도 할 수 있는 일이 없다. 이걸 숨기는 광고는 거짓말이고, 나중에 더 크게 돌아온다.

### 4.2 어떻게 지키나 — 기술을 아는 사람에게

- **암호** AES-256-GCM. 인증 태그가 붙어서 내용이 한 글자라도 바뀌면 열리지 않는다.
- **열쇠 만들기** Argon2id → scrypt → PBKDF2(60만 회) 순으로 기기가 감당하는 가장 강한
  것을 고른다. 기기에 맞춰 강도를 조정하되 **아래 선 밑으로는 어떤 경우에도 안 내려간다**
  (Argon2id 19MiB / scrypt N=2^14 / PBKDF2 60만 회).
- **열쇠 구조** 금고 열쇠(DEK)는 무작위 32바이트다. **PIN 에서 만들지 않는다.**
  PIN · 복구 코드 · 지문 세 갈래로 각각 따로 감싸고, 저장되는 덩어리는 OS 키 저장소의
  기기 열쇠로 한 겹 더 감싼다. 그래서 **PIN 을 바꿔도 저장된 것을 다시 암호화할 필요가 없다.**
- **PIN 확인 방식** 해시를 저장해 비교하지 않는다. 입력한 PIN 으로 열쇠를 만들어 실제로
  열어 보고, 인증 태그가 통과하면 맞는 PIN 이다. **비교할 값이 저장돼 있지 않다.**
- **여러 번 틀렸을 때** 5회 30초 / 6회 1분 / 7회 5분 / 8회 이상 15분.
  세 가지 우회를 다 막았다 — 앱 껐다 켜기, 시계 되돌리기, 기록 파일 지우기.
  (기록 파일만 지우면 오히려 최대 대기가 걸린다.)
- **지문을 새로 등록하면** 지문으로 여는 길만 막힌다. PIN·복구 코드는 그대로 산다.
  지문 열쇠와 기기 열쇠를 따로 둔 덕이다.

### 4.3 일부러 못 하게 한 것

- **뒷문이 없다.** PIN 과 복구 코드와 백업을 모두 잃으면 **되살릴 수 없다.**
  뒷문을 두면 그 문으로 남도 들어온다. 이 문장을 최초 설정과 설정 화면 양쪽에 그대로 띄운다.
- **인터넷을 안 쓴다.** `INTERNET` 권한을 아예 막아 뒀다. 광고·분석·오류수집 도구가
  하나도 없다. **못 넣은 게 아니라 안 넣었다.** 그런 도구 하나가 공격 표면 하나다.

## 5. 성능

정직하게 적는다. **재 본 것과 안 재 본 것을 구분한다.**

| | |
|---|---|
| 자바스크립트 묶음 | 2.5MB |
| 자동 검사 96개 도는 시간 | 약 5초 |
| 금고 여는 데 걸리는 시간 | **설계 목표 0.5~1초.** 기기에서 재지 않았다 |
| 항목 1,000개일 때 검색 속도 | **재지 않았다** |
| 앱 설치 크기 | **재지 않았다** |

금고 여는 시간을 일부러 0.5~1초로 잡았다. 더 빠르게 만들 수 있지만 그러면 열쇠 만들기가
약해진다. **느린 게 아니라 그만큼 단단한 것이다.**

## 6. 다른 앱과 무엇이 다른가

### 6.1 진짜 차이는 구조다

대부분의 비밀번호 관리자는 이렇게 생겼다.

```
내 폰 ──인터넷──> 회사 서버 ──> 내 다른 기기
```

편하다. 기기를 여러 대 쓰면 알아서 맞춰지고, 폰이 부서져도 서버에 남는다.
대신 **계정을 만들어야 하고, 내 것이 회사 서버를 거친다.**

잠김은 이렇게 생겼다.

```
내 폰 ── 끝
```

**서버가 없다. 계정이 없다. 인터넷 권한이 없다.**

이건 자랑이자 한계다. 양쪽을 같이 말해야 한다.

| | 얻는 것 | 잃는 것 |
|---|---|---|
| 서버 없음 | 회사가 털려도 내 것은 안 샌다. 회사가 망해도 앱은 돈다. 회사도 내 것을 못 본다 | 기기 사이 자동 맞춤이 없다. 백업은 내가 챙겨야 한다 |
| 계정 없음 | 가입할 것도, 잊을 것도, 털릴 것도 없다 | 비밀번호 잊었을 때 "메일로 재설정"이 없다 |
| 인터넷 권한 없음 | 앱이 어디로도 뭘 보낼 수 없다. **권한 목록에서 눈으로 확인된다** | 업데이트는 스토어를 통해서만 |

**마지막 줄이 핵심 무기다.** "우리는 안 보냅니다"는 누구나 말한다.
**"보낼 수가 없습니다 — 권한 목록을 직접 보세요"는 사용자가 확인할 수 있다.**

### 6.2 두 번째 차이 — 누구를 위해 만들었나

대부분의 비밀번호 관리자는 컴퓨터를 잘 다루는 사람 기준으로 만들어져 있다.
잠김은 처음부터 **부모님이 쓸 수 있는 것**을 목표로 했다.

- 본문 글씨 16sp, 누르는 곳 최소 48dp
- 글꼴을 200%로 키워도 화면이 안 깨진다 (실기기에서 확인했다)
- **전문 용어를 안 쓴다.** "복호화" 대신 "열기", "마스터 패스워드" 대신 "PIN(핀)"
- 화면 8개가 전부다. 설정에 파묻힌 기능이 없다

이건 기능표에 안 나오지만, 실제로 부모님께 깔아 드려 본 사람은 안다.

### 6.3 경쟁 앱 이야기를 쓸 때 — 주의

**다른 앱 이름을 대고 공격하지 않는다.** 세 가지 이유다.

1. 우리 문구의 상한선은 위협 모델 표다. 남을 공격하면 **우리도 같은 잣대로 검사받는다.**
   우리는 루팅 기기와 악성앱 앞에서 방어 불가라고 적어 두었다.
2. 사고가 났던 회사를 들먹이는 광고는 법적으로 위험하고, 보는 사람도 불편해한다.
3. 구조가 다르지 실력이 다른 게 아니다. 클라우드 동기화가 필요한 사람에게는
   그쪽이 맞는 답이다. **우리는 다른 필요에 답하는 앱이다.**

쓴다면 이렇게 쓴다.

> ❌ "○○는 서버가 털렸습니다. 잠김은 안전합니다."
> ⭕ "잠김은 서버가 없습니다. 털릴 서버 자체가 없습니다."

경쟁 앱의 구체적인 기능·가격·사고 이력을 문구에 넣어야 한다면,
**쓰기 직전에 직접 확인하고 출처를 남긴다.** 이 문서에는 적지 않는다 — 시간이 지나면
틀린 정보가 되고, 틀린 채로 광고에 남는다.

## 7. 홍보 방향

### 7.1 누구에게

| 순위 | 대상 | 걸리는 말 |
|---|---|---|
| 1 | **50~70대, 그리고 그 자녀** | "부모님 폰에 깔아 드리세요" |
| 2 | 클라우드에 올리기 싫은 사람 | "서버가 없습니다" |
| 3 | 종이 수첩에 적어 두는 사람 | "수첩보다 안전하고, 수첩만큼 단순합니다" |

**1번이 제일 크다.** 자녀가 깔아 드리고, 부모님이 쓴다. 그래서 광고는 **자녀에게** 하고
앱은 **부모님에게** 맞춰야 한다. 지금 UI 가 딱 그 구조다.

### 7.2 어떤 말로

**핵심 한 문장** (모든 매체에 이것부터)

> 서버가 없습니다. 계정도 없습니다. 인터넷 권한조차 요구하지 않습니다.

**받쳐 주는 세 문장**

1. 내 폰 안에서 암호로 잠급니다. 어디로도 보내지 않습니다.
2. 회사가 망해도 앱은 그대로 돕니다. 보내는 곳이 없으니까요.
3. PIN(핀)을 잊어도 복구 코드로 엽니다. 셋 다 잃으면 열 수 없습니다 — 그렇게 만들었습니다.

**세 번째 문장을 빼지 않는다.** 불편한 사실을 먼저 말하는 쪽이 결국 믿음을 산다.
그리고 이걸 안 말하면 복구 코드를 안 적어 두는 사람이 생긴다. 그게 진짜 사고다.

### 7.3 보여 줄 것

말보다 이게 세다.

1. **안드로이드 앱 정보 → 권한 화면 캡처.** 권한이 하나도 없는 화면.
   이건 우리가 만든 그림이 아니라 **안드로이드가 보여 주는 화면**이다.
2. **비행기 모드로 켜서 다 쓰는 영상.** 인터넷을 끊어도 전부 동작한다.
3. **앱 데이터 파일을 열어 본 화면.** 평문이 하나도 없다.

### 7.4 어디에

- 스토어 등록 정보 — 첫 두 줄에 "서버 없음 · 계정 없음"
- 부모님 세대를 다루는 커뮤니티 (자녀 쪽 접점)
- 보안 관심 커뮤니티 — 여기는 4.2 의 기술 내용을 그대로 던져도 된다.
  **다만 4.1 의 "방어 불가" 두 줄을 같이 내야 한다.** 이 사람들은 그걸로 신뢰를 판단한다.

## 8. 쓰면 안 되는 말

명세 8장이다. **번역문에도 그대로 적용된다** (`docs/국제화.md` 7장).

| 쓰지 않는다 | 대신 |
|---|---|
| 절대 안전 · 100% 안전 | 기기 안에서 암호로 잠급니다 |
| 해킹 불가 · 뚫을 수 없는 | 잠긴 폰을 잃어버려도 내용은 암호문입니다 |
| 군사급 · 은행급 | AES-256-GCM |
| 완벽한 · 무결점 | (쓰지 않는다) |
| absolutely safe / unhackable / military-grade | encrypted on your device |
| 絶対安全 / ハッキング不可能 | 端末内で暗号化 |

**"복구 불가"를 부드럽게 바꾸지 않는다.** "복구가 어려울 수 있습니다" 정도로 누그러뜨리면
사용자가 복구 코드를 안 적어 둔다.

---

## 9. 아직 아닌 것 — 홍보에 쓰면 안 됨

- **iOS** — 코드는 있으나 기기에서 확인하지 않았다. "아이폰도 됩니다"라고 쓰지 않는다.
- **다국어** — 준비만 해 두었다 (`docs/국제화.md`). 아직 한국어뿐이다.
- **자동 채우기(오토필)** — 없다. MVP 에서 일부러 뺐다.
- **성능 수치** — 5장의 "재지 않았다" 항목을 숫자로 쓰지 않는다.
- **글꼴 200% 확대** — 코드는 그렇게 짰지만 기기에서 확인하지 않았다.

## 10. 스토어 등록 정보 초안

**짧은 설명 (80자)**

> 서버도 계정도 없는 비밀번호 금고. 내 폰 안에서만 잠급니다.

**긴 설명**

```
아이디와 비밀번호를 내 폰 안에만 넣어 두는 금고입니다.

■ 서버가 없습니다
어디로도 보내지 않습니다. 보낼 곳 자체가 없습니다.
앱 정보 → 권한 화면을 열어 보세요. 요구하는 권한이 하나도 없습니다.

■ 계정을 만들지 않습니다
가입도, 로그인도, 이메일도 필요 없습니다.

■ 크고 쉽게 만들었습니다
글씨가 큽니다. 버튼이 큽니다. 어려운 말을 쓰지 않습니다.
글꼴을 키워 쓰셔도 화면이 깨지지 않습니다.

■ 여는 방법 세 가지
PIN(핀) · 지문과 얼굴 · 복구 코드

■ 꼭 알아 두실 것
PIN(핀)과 복구 코드와 백업 파일을 모두 잃으면 금고를 열 수 없습니다.
저희도 열어 드릴 수 없습니다. 그렇게 만들었습니다.
처음 설정할 때 나오는 복구 코드를 꼭 종이에 적어 두세요.

기기 안에서 AES-256-GCM 으로 암호화합니다.
자세한 내용은 개인정보 처리방침을 봐 주세요.
```

**이 초안을 쓰기 전에 8장 표로 한 번 훑는다.**
