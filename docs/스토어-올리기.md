# 구글 플레이에 올리기

**이 문서를 쓴 날: 2026-09-01.** 스토어 정책은 자주 바뀐다. 아래 내용은 등록 화면에서
직접 확인하면서 진행한다. 이 문서가 틀렸으면 화면이 맞다.

## 0. 먼저 알아 둘 것 — 시간이 제일 오래 걸리는 부분

**개인 개발자 계정으로 처음 앱을 내려면, 바로 공개 출시가 안 된다.** (2026-09-19 확인)
**2023년 11월 13일 이후 만든 개인 계정**에 구글이 요구하는 절차다.

- 비공개 테스트를 먼저 한다
- 테스터 **12명 이상**이 **14일 이상 연속으로** 참여해 있어야 한다
- 그 뒤에 공개 출시(프로덕션) 권한을 신청한다

**즉 앱이 다 됐어도 최소 2주 이상 걸린다.** 여기부터 계산해야 한다.
구글 공식 문서는 이 요건을 **"새 개인 개발자 계정"** 에 건다고 적는다. 사업자(조직) 계정은
대상이 아닌 것으로 읽히지만, **등록 화면에서 직접 확인한다.**

테스터 12명은 가족·지인의 구글 계정 이메일이면 된다. 실제로 써 볼수록 좋다.
**절차는 1-1 에 자세히 적었다.**

## 1. 개발자 계정 만들기

https://play.google.com/console 에서 가입한다.
**등록비 미화 25달러, 한 번만 낸다** (연회비 아님).

### 개인이냐 사업자냐

가입할 때 고른다. 나중에 바꾸기 어려우므로 처음에 정한다.

| | 개인 | 사업자(단체) |
|---|---|---|
| 확인 서류 | 신분증 | 사업자등록증 + **D-U-N-S 번호** |
| 준비 기간 | 며칠 | D-U-N-S 발급에 **몇 주** 걸릴 수 있다 |
| 테스터 12명 × 14일 | **필요** (확인함) | 공식 문서는 개인 계정만 대상 (아래 ⚠️) |
| 스토어에 공개되는 것 — 무료 앱 | 이름·나라·이메일 | 사업장 주소 |
| 스토어에 공개되는 것 — **유료 앱** | **집 주소 전체** | 사업장 주소 |

⚠️ **"사업자는 테스터 면제" 는 공식 문서를 그렇게 읽은 것이다.** 문서 제목이 "새 개인
개발자 계정의 앱 테스트 요건" 이다. 사업자를 고르는 이유가 이것이라면 **등록 화면에서
한 번 더 확인한다.**

**주소 공개 — 유료냐 무료냐로 갈린다** (2026-09-19 확인). 개인 계정이라도 무료 앱이면
이름·나라·이메일만 나온다. 그런데 **유료 앱이나 앱 안 결제가 있으면 주소 전체가 나온다.**
소비자 보호법 때문이다.

**잠김은 ₩5,500 유료 앱으로 정했다(`docs/가격.md`). 개인으로 등록하면 집 주소가
스토어에 뜬다.** 비밀번호 금고 앱을 만드는 사람에게는 가볍지 않은 문제다.

사업자로 해도 **사업장을 집으로 등록하면 결국 집 주소가 나온다.** 주소를 가리려면
사업장 주소가 따로 있어야 한다.

**무료로 먼저 내고 나중에 유료로 바꾸는 것은 안 된다.** 한 번 무료로 낸 앱은 유료로
못 돌린다(`docs/가격.md` 7장). 주소를 피하려고 무료로 시작하는 길은 없다.

**돈** — 유료로 팔면 수익이 생기고 세금 신고가 따라온다. 해외 매출은 영세율로 따로
신고한다(`docs/가격.md` 6장). **어차피 사업자등록이 필요하다면 계정도 사업자로 하는 게
맞을 수 있다.** 이건 세무사가 판단할 일이다.

**권고** (2026-09-19 고침. 전에는 "무료 앱이니 개인으로 시작" 이었는데, 가격을 정하기
전에 쓴 것이라 지금 계획과 맞지 않았다):

1. **먼저 세무사에게 묻는다** — 유료 앱을 팔 때 사업자등록이 필요한지
2. 필요하다면 → **사업자 계정.** 사업자등록 뒤 D-U-N-S 번호를 신청한다(무료, 몇 주).
   사업장 주소를 따로 둘 수 있으면 집 주소도 가려진다
3. 필요 없고 집 주소 공개가 괜찮다면 → **개인 계정.** 며칠이면 되지만 테스터 12명 ×
   14일을 거친다

계정 종류는 **나중에 바꾸기 어렵다.** 등록 전에 정한다.

### 현황 (2026-09-19)

**사업자등록과 통신판매업 신고를 마쳤다. 사업자(조직) 계정으로 간다.**

다음은 **D-U-N-S 번호**다. 없으면 조직 계정을 아예 만들 수 없다.

- Dun & Bradstreet 에 신청한다. **무료**다
- 무료 신청은 **최대 30일** 걸린다. 나라에 따라 돈을 내면 빨리 해 주는 길을 권하기도 한다
- **사업자등록증의 상호·주소와 D-U-N-S 에 등록되는 영문 상호·주소, 그리고 콘솔에 넣는
  것이 서로 맞아야 한다.** 여기서 어긋나서 되돌아가는 일이 흔하다
- 통신판매업 신고번호도 곁에 둔다. 등록이나 스토어 정보에서 물어볼 수 있다 — 확인은 못 했다

30일은 EAS 빌드 횟수가 10월 1일에 차는 것과 겹친다. D-U-N-S 를 먼저 걸어 두면
기다리는 시간이 겹친다.

## 1-1. 비공개 테스트 — 테스터 12명은 어떻게 세는가

**개인 계정이면 이 절차를 먼저 거쳐야 한다** (2026-09-19 확인). 아래는 그 절차의
얼개다. **정책 세부는 자주 바뀌므로 콘솔 화면이 최종 기준이다.**

**1) 비공개 테스트 트랙을 만든다**
콘솔에서 `테스트 → 비공개 테스트` 로 들어가 트랙을 만들고 `.aab` 를 올린다.

**2) 테스터를 이메일로 등록한다**
이메일 목록에 주소를 직접 넣거나, 구글 그룹 주소 하나를 넣는다. 12명이면 이메일
목록이 간단하다.

⚠️ **반드시 구글 계정 이메일이어야 한다.** 네이버·다음 주소는 안 된다. 그 사람이
폰에서 로그인해 쓰는 구글 계정이어야 한다.

**3) 참여 링크를 보낸다**
콘솔이 링크를 준다. 12명에게 보내면 각자 그 링크를 열고 **"테스터가 되기"를 눌러야**
한다. **이메일만 등록해 놓으면 안 되고 본인이 수락해야 사람 수에 들어간다.**

**4) 깔고 그대로 둔다**
수락하면 플레이스토어에서 받을 수 있다. **14일 동안 지우지 말라고** 부탁한다.

**5) 콘솔이 세어 준다**
"며칠째, 몇 명" 이 나온다. 조건이 차면 공개 출시 신청 버튼이 열린다.

### 확실히 모르는 것

- ~~중간에 한 명이 빠지면 날짜가 처음부터 다시 세어지는지~~ — **확인했다.** 빠졌다가 다시
  들어온 사람은 **그 사람의 14일을 처음부터 다시** 채워야 센다. 그래서 **여유 있게
  14~15명** 모은다
- 정확한 판정 기준(설치만 하면 되는지, 열어 봐야 하는지)

이 앱은 인터넷을 쓰지 않으므로 **구글이 사용 기록을 볼 수 없다.** 그래서 "수락하고
깔아 둔 상태" 가 기준일 가능성이 높다.

### 제일 중요한 것 — 앱 완성을 기다리지 않는다

지금 상태로도 비공개 테스트를 **시작할 수 있다.** 14일은 그냥 흘러가는 시간이고,
그 사이에 새 빌드를 계속 올릴 수 있다.

```
지금 시작    → 14일 동안 앱 다듬기 → 바로 공개 신청
완성 후 시작 → 앱 다듬기 → 그다음 14일 → 공개 신청
```

**2주 차이가 난다.**

순서:
1. 개발자 계정 등록 (본인 확인 며칠)
2. 12~15명 이메일 모으기 ← **지금 할 수 있다**
3. `production` 빌드 한 번 올려서 비공개 테스트 시작
4. 14일 동안 남은 작업 — ~~글꼴 200% 확대, 화면 사진, 처리방침 주소~~ 는 끝났다(2026-09-18)
5. 공개 신청

## 3-1. 화면 사진 찍는 법

폰에서 직접 찍는다. 이 앱은 **화면 찍기를 막아 두었기 때문에** 그냥은 안 찍힌다.
순서를 지켜야 한다.

### ⚠️ 먼저 — 화면 찍기 막기를 잠깐 끈다

명세 5.5 대로 캡처를 막아 두어서, 앱 화면에서 캡처를 누르면 **까맣게 나오거나
아무 일도 안 일어난다.** 폰이 고장 난 것이 아니다.

1. 앱 → 설정 → **화면 찍기 막기**를 **끈다**
2. 사진을 다 찍는다
3. **반드시 다시 켠다** ← 이걸 잊으면 최근 앱 목록에 비밀번호가 그대로 보인다

3번을 잊기 쉽다. 사진 다 찍고 제일 먼저 할 일로 생각한다.

### 그다음 — 시험용 금고를 따로 만든다

**진짜 비밀번호가 찍히면 안 된다.** 스토어 사진은 전 세계에 공개된다.

가장 안전한 길은 **개발용 앱(`잠김 (개발)`)에서 찍는 것**이다. 진짜 앱과 금고가
따로라 실제 계정이 섞일 일이 없다. 화면은 똑같다.

넣을 시험 자료는 **아무 회사 이름도 쓰지 않는 것**이 낫다. 남의 상표를 우리
홍보물에 넣는 것은 따로 확인이 필요한 일이다. 이런 식으로 채운다.

| 어디에서 | 아이디 | 갈래 |
|---|---|---|
| 은행 | `hong1955` | 은행 |
| 카드 | `hong1955` | 카드 |
| 쇼핑몰 | `hong-gd` | 쇼핑 |
| 관공서 | `hong1955` | 관공서 |

비밀번호는 아무 글자나 넣는다. 어차피 화면에는 `●●●●●●●●` 로 가려진다.

### 찍을 화면

**`docs/스크린샷-찍는-법.md` 를 보라.** 무엇을 몇 장 찍는지는 그 문서가 정본이다.

여기에도 표를 두었다가 두 문서가 서로 다른 말을 하게 됐다 — 이쪽은 네 장짜리
옛 계획이고 잠금 화면이 1번이었는데, 저쪽은 일곱 장이고 금고 목록이 1번이다.
자동 완성 사진은 이쪽에 아예 없었다. 그 사이에 자동 완성이 완성됐기 때문이다.
한쪽만 고치면 이렇게 된다. 그래서 표를 지우고 넘긴다.

### 절대 찍지 않는다

- **복구 코드 화면.** 진짜 코드가 찍힌다. 시험용이라도 습관을 들이지 않는다.
- **비밀번호가 `보기` 로 드러난 상태.**
- 실제로 쓰는 계정이 하나라도 보이는 화면.

### 안드로이드 권한 화면은 넣지 않는 쪽으로 한다

폰 설정 → 앱 → 잠김 → 권한 에 **인터넷이 없다**는 것이 보이는 그 화면이 우리
주장을 제일 세게 보여 준다. 넣고 싶은 마음이 든다.

**그런데 스토어 사진은 앱 화면이어야 한다.** 구글이 만든 시스템 화면을 올리면
반려될 수 있다. **확인하지 못했다** — 넣으려면 먼저 규정을 확인하고, 넣더라도
앞의 두 장에는 두지 않는다.

대신 **설명 문구**에 적는다. 초안에 이미 들어 있다.

> 인터넷 권한을 요청하지 않습니다. 권한 목록에서 확인해 보세요.

**(2026-09-18 정정)** 전에는 "요구하는 권한이 하나도 없습니다" 라고 적었다.
사실이 아니다. 폰에 깔고 권한을 직접 읽어 보니 **알림** 하나가 있다 — 백업하라고
알려 주는 기능(명세 6.3)이 쓴다. 기기 안에서만 도는 알림이고 인터넷은 쓰지 않는다.

"직접 확인해 보세요" 라고 말하는 앱이다. 확인해 본 사람이 알림을 발견하면 그 한
문장 때문에 나머지 말까지 의심받는다. 그래서 **사실인 것만** 말한다 — 인터넷이
없다는 것. 이 앱의 진짜 무기는 그쪽이고, 그건 틀림없다.

이게 더 낫기도 하다. 우리가 보여 주는 것보다 **사용자가 직접 확인하는 것**이 세다.

### 크기

폰 사진은 세로로 찍으면 대체로 맞는다. **정확한 규격은 플레이 콘솔이 올릴 때
알려 준다** — 안 맞으면 그 자리에서 퇴짜를 놓으므로 미리 재느라 애쓸 것 없다.
글꼴 크기는 **보통으로 되돌려 놓고** 찍는다. 200% 로 키운 화면은 예뻐 보이지 않는다.

## 4. 올릴 파일 만들기

스토어는 `.apk` 가 아니라 **`.aab`** 를 받는다. `production` 프로필이 그것이다.

```powershell
cd C:\Users\kim\safety
git pull origin claude/jamgim-vault-app-z0v7sa
npx eas-cli build --platform android --profile production
```

다 되면 `.aab` 파일을 내려받아 플레이 콘솔에 올린다.

**서명 열쇠**는 EAS 가 만들어 보관한다. 이 열쇠를 잃으면 **같은 앱을 갱신할 수 없다.**
`npx eas-cli credentials` 로 백업을 받아 안전한 곳에 둔다. (금고 복구 코드와 같은 성격이다.)

### 버전 올리기

두 번째부터는 올릴 때마다 숫자를 키워야 한다. 같은 숫자는 거부된다.

| `app.json` | 지금 | 뜻 |
|---|---|---|
| `version` | `0.1.0` | 사람이 보는 버전 |
| `android.versionCode` | `1` | 구글이 보는 번호. **올릴 때마다 +1** |

## 6. 문구를 쓸 때 지킬 선 (명세 8장)

`docs/위협모델.md` 의 표가 모든 문구의 상한선이다. **그 표보다 강한 말은 쓰지 않는다.**

| 쓰지 않는다 | 대신 |
|---|---|
| 절대 안전 · 100% 안전 | 기기 안에서 암호로 잠급니다 |
| 해킹 불가 · 뚫을 수 없는 | 잠긴 폰을 잃어버려도 내용은 암호문입니다 |
| 군사급 · 은행급 | AES-256-GCM |

**"복구 불가" 를 부드럽게 바꾸지 않는다.** PIN·복구 코드·백업을 모두 잃으면 열 수 없다는
것은 이 앱의 설계다. 누그러뜨리면 사용자가 복구 코드를 안 적어 둔다.

**아직 사실이 아닌 것은 쓰지 않는다** — 아이폰 지원, 다국어, 자동 채우기.
자세한 것은 `docs/제품소개.md` 9장.
