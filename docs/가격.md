# 잠김 — 얼마에 팔 것인가

2026-09-02 작성. 숫자 중 일부는 **직접 확인해야 한다** (8장).

---

## 0. 먼저 — 인앱 결제는 이 앱을 깬다

가격 이야기를 하기 전에 이것부터 짚어야 한다.

**인앱 결제에는 인터넷 권한이 필요하다.** 구글 결제 라이브러리가 구글 서버와
통신해야 하기 때문이다. 그런데 이 앱의 유일한 진짜 차별점은 인터넷 권한이
**아예 없다**는 것이다.

인앱 결제를 넣으면 이렇게 된다.

| | 지금 | 인앱 결제를 넣으면 |
|---|---|---|
| 스토어 권한 화면 | 권한 없음 | **인터넷** |
| 홍보 문구 | "인터넷에 연결하지 않습니다" | 쓸 수 없다 |
| 사용자가 확인하는 법 | 비행기 모드로 켜 보면 된다 | 확인 불가 |

마지막 줄이 핵심이다. 지금은 **사용자가 우리 말을 믿지 않아도 스스로 확인할 수
있다.** 비행기 모드로 켜서 다 되면 우리 말이 맞는 것이다. 이 확인 가능성이
비밀번호를 맡기는 이유의 전부다.

돈 받는 방식 때문에 그걸 버리면, 우리는 그냥 기능 적은 비밀번호 앱이 된다.
1Password 나 Bitwarden 과 같은 자리에서 싸워야 하는데 그 싸움은 진다.

**그래서 가격 구조는 인터넷 권한을 요구하지 않는 것 중에서 고른다.**

## 1. 쓸 수 있는 방법

| 방법 | 인터넷 권한 | 서버 | 쓸 수 있나 |
|---|---|---|---|
| **유료 앱** (스토어가 대신 팔아 준다) | **불필요** | 불필요 | ✅ |
| 무료 + 인앱 결제 | 필요 | 불필요 | ❌ 0장 |
| 구독 | 필요 | 사실상 필요 | ❌ 0장 |
| 무료 + 광고 | 필요 | — | ❌ 절대 안 됨 (3장) |
| 완전 무료 + 후원 | 불필요 | 불필요 | 수입이 없다 |

**유료 앱만 남는다.** 그리고 이건 억지로 남은 것이 아니라 오히려 잘 맞는다.

유료 앱은 구글이 스토어에서 대신 팔아 준다. 앱 안에 결제 코드가 한 줄도 없다.
사용자가 스토어에서 사면 스토어가 설치해 준다. 앱은 자기가 돈 받고 팔린 것을
알 필요조차 없다.

### 광고는 왜 "절대 안 됨" 인가

광고는 인터넷 권한만의 문제가 아니다. 광고망은 기기 식별자를 읽어 밖으로
보낸다. **비밀번호 금고 앱이 사용자를 추적하는 것**이다. 이건 기능 하나를
포기하는 문제가 아니라 앱의 존재 이유와 정면으로 부딪힌다.

## 2. 구독을 하지 않는 이유

돈만 보면 구독이 낫다. 한 번 팔고 끝나는 것보다 매년 들어오는 것이 크다.
경쟁 앱들도 전부 구독이다.

**그런데 우리는 매년 받을 명분이 없다.**

구독으로 파는 것은 서버다. 기기 간 동기화, 클라우드 백업, 유출 감시 — 매달
돈이 나가는 것들이라 매달 받는 것이 맞다. 우리는 그게 하나도 없다. 앱을 한 번
만들어 폰에 넣어 드리면 그 뒤로 우리가 쓰는 돈이 없다.

없는 서비스에 매년 돈을 받는 것은, 우리가 스스로 정한 정직함의 기준에 안 맞는다.

한 번 사고 끝나는 것은 **약점이 아니라 홍보 문구**다.

> 한 번 사시면 끝입니다. 매달 나가는 돈이 없습니다.

중장년층이 주 대상이다. 이분들이 구독을 싫어하는 것은 비싸서가 아니라
**언제 얼마가 빠져나가는지 모르는 것이 불안해서**다.

## 3. 체험판 문제 — 그리고 백업 파일이 답이다

유료 앱의 진짜 약점은 이것이다. **사 보기 전에는 못 써 본다.**

구글 플레이는 유료 앱을 산 뒤 짧은 시간 안에 자동 환불해 준다(시간은 8장에서
확인). 하지만 "환불받으면 되니 일단 사세요" 는 비밀번호 앱에 특히 안 통한다.
안 그래도 못 믿어서 망설이는 사람에게 돈부터 내라고 하는 것이다.

### 앱 두 개로 푼다

| | |
|---|---|
| `잠김 체험판` | 무료. 항목 **5개까지**. 인터넷 권한 없음 |
| `잠김` | 유료. 항목 무제한. 인터넷 권한 없음 |

개수 제한은 **폰 안에서 세면 되므로 인터넷이 필요 없다.** 서버에 물어볼 것이
없다.

**그리고 옮기는 길이 이미 있다.** 우리는 암호화된 백업 파일을 내보내고 가져오는
기능을 이미 만들어 두었다 (명세 6장). 체험판에서 내보내고 유료판에서 가져오면
끝이다. 이 기능을 만들 때 생각하지 않았던 쓸모다.

옮기는 길이 없으면 체험판은 오히려 해롭다. 5개 넣어 보고 마음에 들어 샀는데
처음부터 다시 넣어야 하면, 그 순간 기분이 상한다.

### 5개가 맞는 숫자인가

- 너무 적으면(2~3개) 제대로 못 써 보고 판단한다
- 너무 많으면(20개) 그냥 체험판만 쓴다 — 보통 사람이 정말 중요한 계정은 열 개 안팎이다

5개면 은행 하나, 카드 하나, 쇼핑 하나 정도는 넣어 보고 **"아, 이렇게 쓰는
거구나"** 를 알 수 있다. 그리고 금방 모자라진다.

## 4. 가격표

### 권하는 것

| | |
|---|---|
| **잠김 체험판** | **무료** — 항목 5개까지 |
| **잠김** | **₩5,500** — 한 번 사면 끝 |

한 가지 가격만 둔다. 등급을 나누면 "무엇이 빠졌는지" 를 설명해야 하고,
설명이 길어지면 중장년층 대상 앱으로는 실패다.

### 왜 5,500원인가

한국 스토어 가격은 **부가세가 포함된 값**으로 적는다. 5,500원이면 부가세를
뺀 값이 딱 5,000원이라 정산이 깔끔하다.

| 가격 | 문제 |
|---|---|
| ₩1,200 | **너무 싸서 안 믿는다.** 비밀번호를 맡길 앱이 커피 한 잔 값의 1/5 이면 "대충 만든 것" 으로 읽힌다 |
| ₩3,900 | 무난하지만 위와 같은 인상이 남는다 |
| **₩5,500** | **커피 한 잔.** 한 번이면 끝이라는 말과 같이 놓으면 설득이 쉽다 |
| ₩9,900 | 선물로는 괜찮지만 자기가 쓰려고 사기엔 망설인다 |

비밀번호 금고는 **싼 것이 미덕이 아닌 드문 물건**이다. 자물쇠를 살 때 제일 싼
것을 고르지 않는 것과 같다.

### 파는 이야기는 "선물" 이다

이 앱을 살 사람은 두 종류다.

1. 본인이 쓰려고 사는 중장년층
2. **부모님께 사 드리는 자녀**

2번이 크다. 5,500원은 자녀 입장에서 고민할 금액이 아니다. 스토어 설명에
이 말이 들어가야 한다.

> 부모님 폰에 깔아 드리세요. 한 번만 사면 됩니다.

## 5. 손에 들어오는 돈

수수료율은 8장에서 확인해야 한다. 아래는 **15% 로 가정한** 예시다.

```
₩5,500  사용자가 내는 돈
  −500  부가세 10%
₩5,000  과세 전 매출
  −750  구글 수수료 15% (가정)
₩4,250  내 몫
```

| 판매 | 내 몫 (가정) |
|---|---|
| 10개 | ₩42,500 |
| 100개 | ₩425,000 |
| 1,000개 | ₩4,250,000 |

**본전은 9개다.** 구글 개발자 등록비가 한 번 내는 $25(약 35,000원)이고 그 밖에
나가는 돈이 없다. 서버가 없어서 유지비가 0원이다.

이게 서버 없는 구조의 숨은 장점이다. **안 팔려도 손해가 안 난다.** 서버가
있으면 사용자가 늘 때마다 돈이 나가고, 안 팔리면 서버비만 나간다.

## 6. 해외에서 사는 사람은 어떻게 되나

### 우리가 할 일이 거의 없다

| | 누가 하나 |
|---|---|
| 원화 → 현지 통화 환산 | 구글 |
| 현지 결제 수단 (카드·통신사 결제·현지 간편결제) | 구글 |
| 현지 세금 징수·납부 (미국 판매세, EU VAT, 일본 소비세) | 구글 |
| 환불 처리 | 구글 |
| **어느 나라에 팔지, 얼마에 팔지 정하기** | **우리** |

0장에서 본 것이 여기서도 그대로다. 유료 앱은 **스토어가 파는 것**이라 앱에
결제 코드가 한 줄도 없다. 미국 사람이 사든 일본 사람이 사든 우리 앱은 자기가
팔렸다는 사실조차 모른다.

돈은 전 세계 판매가 **한 덩어리로 합쳐져 원화로 국내 계좌에** 들어온다. 나라별로
따로 받는 것이 아니다. 개발자 계정을 만들 때 결제 프로필(주소·계좌·세금 정보)을
한 번 등록하면 그 뒤로 할 일이 없다.

### 세금 신고는 나눠야 한다

**국내 매출과 해외 매출을 구분해서 신고한다.** 해외 매출은 부가세 **영세율**이
적용된다 — 부가세를 안 내는 대신, 영세율매출명세서·외화획득명세서·구글 정산
내역을 신고할 때 함께 낸다. 나라별 내역은 구글 정산서에 나오므로 그것을 쓴다.

여기서부터는 세무 영역이라 세무사와 상의한다.

### 그런데 지금 해외에 팔면 안 된다

**앱이 한국어뿐이다.** 미국 사람이 사면 아무것도 못 읽는다. 환불받고 별 하나를
남긴다. **별점은 한 번 떨어지면 회복이 오래 걸린다.** 5,500원 몇 건 벌자고
치를 값이 아니다.

| 단계 | 어디에 | 언제 |
|---|---|---|
| 1 | **한국만** | 지금 |
| 2 | + 미국·캐나다·일본·호주·뉴질랜드 | 지금 해도 된다 |
| 3 | 전 세계 | **영어판이 들어갔다 (2026-09-03).** 실기기 확인 뒤 |

2단계가 지금 해도 되는 이유가 있다. **스토어 설명이 한국어라 한국어로 검색하는
사람에게만 보인다.** 저 나라들에서 한국어로 비밀번호 앱을 찾는 사람은 교포이거나
이주민이고, 그분들이 바로 이 앱의 대상이다 — `docs/국제화.md` 에 "폰은 영어인데
앱은 모국어로 보고 싶은 사람" 이라고 적어 둔 그분들이다. 앱은 이미 그것을 한다.

3단계는 이제 앱 쪽 준비가 끝났다. 영어 폰에서 열면 영어로 뜨고, 설정에 "언어"
항목도 나온다 (`docs/국제화.md` 5-2). 남은 것은 **스토어 설명의 영어판**과
실기기 확인이다 — 스토어에 적는 글은 앱 안 문장과 별개다.

### 가격은 나라마다 손으로 다듬는다

구글이 자동으로 환산해 주지만 **어색한 숫자가 나온다.** 5,500원을 그대로 환산하면
$4.13 같은 값이 된다. 아무도 그렇게 팔지 않는다.

주요 나라만 손으로 고친다 — 미국 $3.99, 일본 ¥600 하는 식이다. 나라 수가 많아
보여도 실제로 팔릴 곳은 열 곳 안팎이라 그것만 만지면 된다.

한 가지 더. 나라마다 **부가세를 가격에 포함해 적는지 아닌지가 다르다.** 한국과
일본은 포함해서 적고, 미국은 판매세가 주마다 달라 나중에 붙는다. 그래서 미국
사용자가 실제로 내는 값은 우리가 적은 $3.99 보다 조금 높다. 이건 우리 손을
떠난 부분이다.

## 7. 하지 말아야 할 것

- **광고** — 1장에서 본 대로. 논의 대상이 아니다.
- **"평생 이용권" 이라는 말** — 구독처럼 들린다. "한 번 사면 끝" 이라고 쓴다.
- **무료로 뿌린 뒤 유료로 바꾸기** — 이미 받은 사람은 계속 무료다. 되돌릴 수 없다.
  **먼저 유료로 내고 나중에 내리는 것은 되지만 그 반대는 안 된다.**
- **가격을 자주 바꾸기** — 산 사람이 손해 본 기분이 든다. 올릴 때 이미 산 사람은
  다시 안 내도 되지만, 그 사실을 아무도 모른다.
- **기능을 빼서 등급 만들기** — 백업을 유료로 돌리는 식. 백업은 안전장치다.
  안전장치를 돈으로 막으면 우리가 명세 6장에서 하려던 것과 정반대가 된다.

한 번 사고 끝나는 5,500원은 저들의 **3개월치**도 안 된다. 이건 가격표에
쓸 만한 비교다. 다만 **경쟁 앱을 이름 대고 깎아내리지 않는다** —
`docs/제품소개.md` 에 적어 둔 그대로다. 남을 공격하면 우리도 같은 잣대로
검사받는데, 우리는 루팅된 기기와 악성앱 앞에서는 방어 못 한다고 스스로 적어
둔 앱이다.

## 9. 정리

| | |
|---|---|
| 구조 | 무료 체험판 + 유료 앱. **인앱 결제 없음, 구독 없음, 광고 없음** |
| 체험판 | 항목 5개까지. 백업 파일로 유료판에 그대로 옮긴다 |
| 가격 | **₩5,500** 한 번 |
| 파는 이야기 | "한 번 사면 끝입니다" · "부모님 폰에 깔아 드리세요" |
| 파는 나라 | 처음엔 **한국만**. 한국어판인 채로 미국·캐나다·일본·호주까지는 열어도 된다 (한국어로 찾는 사람에게만 보인다). 전 세계는 영어판이 나온 뒤 |
| 해외 결제 | 구글이 다 한다 — 환산·결제 수단·현지 세금·환불. 돈은 원화로 합쳐서 들어온다 |
| 본전 | 9개 (개발자 등록비 $25 말고는 나가는 돈이 없다) |

**가격 구조가 앱의 설계와 같은 말을 한다.** 서버가 없어서 구독할 것이 없고,
인터넷이 없어서 인앱 결제를 못 하고, 추적하지 않아서 광고를 못 붙인다.
남은 것이 "한 번 사고 끝" 하나뿐인데, 그게 마침 중장년층이 제일 편해하는
방식이다.
