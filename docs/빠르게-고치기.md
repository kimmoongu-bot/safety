# 빠르게 고치기 — 매번 빌드하지 않는 법

화면 색·크기·글자·배치를 고칠 때마다 클라우드 빌드를 15~20분씩 기다릴 필요가 없다.
**개발용 빌드를 한 번 깔아 두면 그 뒤로는 몇 초 만에 바뀐다.**

## 어떻게 되는 것인가

```
지금        코드 고침 → 클라우드 빌드 15~20분 → 큐알 → 설치 → 확인
개발용 빌드  코드 고침 → 폰에서 흔들기 → 몇 초 → 확인
```

폰에 깐 개발용 앱이 **피시가 켜 놓은 서버에서 화면 코드를 받아온다.** 앱 껍데기는
그대로 두고 알맹이만 바꾸는 것이다.

## 처음 한 번 (15~20분)

개발용 앱을 폰에 깐다. 이건 한 번만 하면 된다.

```powershell
cd C:\Users\kim\safety
npx eas-cli build --platform android --profile development
```

`preview` 가 아니라 **`development`** 다. 다 되면 큐알로 폰에 깐다.
(배포용 앱과 따로 깔린다. 둘 다 두어도 된다.)

## 그다음부터 (몇 초)

**피시에서** — 켜 두고 그대로 둔다.

```powershell
cd C:\Users\kim\safety
npm start
```

큐알이 뜬다. **폰의 개발용 앱**으로 그 큐알을 찍으면 붙는다.

이제 내가 코드를 고치고 나면:

1. 피시에서 `git pull`
2. 폰을 흔들거나, 피시 창에서 `r` 을 누른다
3. 몇 초 뒤 바뀐 화면이 나온다

**폰과 피시가 같은 와이파이에 있어야 한다.** 안 되면 `npx expo start --tunnel` 로
돌리면 인터넷을 거쳐 붙는다 (조금 느리다).

## 인터넷 권한 — 조심할 것

이 앱은 인터넷 권한을 막아 두었다 (명세 1장). 그런데 개발용 빌드는 피시에 접속해야
하므로 인터넷 권한이 필요하다.

`app.config.js` 가 **`development` 프로필일 때만** 권한을 푼다. `preview` ·
`production` · 프로필 없음은 전부 막힌 채다.

`tests/appConfig.test.ts` 가 이 규칙을 지킨다. 배포용 프로필에서 인터넷이 열리면
검사가 실패한다.

**개발용 빌드는 폰에 개발용으로만 깔고, 스토어에 올리지 않는다.**

## 이때는 다시 빌드해야 한다

알맹이가 아니라 껍데기가 바뀌는 일이다.

- 라이브러리를 새로 넣거나 뺐을 때
- `app.json` 의 플러그인 · 권한 · 아이콘이 바뀌었을 때
- 글꼴 파일을 넣거나 바꿨을 때

이런 것을 고치면 내가 "이번엔 다시 빌드해야 합니다" 라고 알린다.
