### 2026-10-16 디자인 — 무엇이 바뀌었나

- 잠금 화면을 **위·가운데·아래** 세 덩어리로 다시 짰다. 로고는 위, 입력 표시는
  가운데, 숫자판과 버튼은 엄지가 닿는 아래. 글꼴 200% 에서는 스크롤된다.
- 숫자판을 **가로로 긴 직사각형**으로. 마지막 줄은 `0` 과 `지우기` 둘이 폭을 반씩.
- 설정의 고르는 칸과 켜짐·꺼짐에서 **네모를 빼고 밑줄**로. 고른 것은
  진한 글자 + 굵은 꼴 + 밑줄 **셋**으로 말한다 (색만으로 가르지 않는다).
- 기본 버튼 바탕을 새까만 검정에서 **먹색 `#3F3F3F`** 로.
- 어두운 화면의 **흰 줄을 회색 `#4E5257`** 으로, 바탕을 `#121212` 로.
  흰 줄은 바탕보다 밝아서 빛나 보였다 — 밝은 벌을 그대로 뒤집으면 안 된다.
- 보이는 말에서 **`PIN` 을 없앴다.** 한국어 `잠금 번호`, 영어 `passcode`,
  러시아어 `код доступа`. 일본어는 이미 `暗証番号`. `지움` → `지우기`.

## 날마다 쓰는 명령

개발용 앱을 폰에서 보며 고칠 때. 창 두 개를 쓴다.

```powershell
# 창 1 — 화면 서버
npm run dev

# 창 2 — 폰 붙이기 (USB 선을 뽑았다 꽂으면 이것만 다시)
npm run dev:phone
```

왜 이렇게 묶었는지는 `tools/dev/start.ts` 머리말에 적었다. 요약하면,
`--localhost` 는 서버를 IPv6 이름에만 묶는데 `adb reverse` 는 IPv4 로 찾아가서
서로 다른 문이 된다.

고친 것을 피시로 받을 때:

```powershell
git pull --no-edit origin claude/jamgim-vault-app-z0v7sa
```

클라우드 쪽에서는 그게 안 보여서 같은 일을 두 번 하게 된다. 실제로 그랬다
